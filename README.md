# Snake

A classic Snake game in plain HTML, CSS and JavaScript — no build step, no dependencies.

## Play

Open `index.html` in any browser, or enable **GitHub Pages** for this repo
(Settings → Pages → Deploy from branch → `main` / root) and play it online.

## Controls

| Action | Keyboard | Mobile |
| ------ | -------- | ------ |
| Move   | Arrow keys or WASD | Swipe or on-screen pad |
| Pause  | Space | — |
| Restart after game over | Any direction | Any direction |

## Features

- Speeds up a little with every apple
- Best score saved in your browser
- Input buffering so quick turns don't get lost
- Works on desktop and mobile

## Files

- `index.html` — page layout and styles
- `game.js` — game logic and rendering
